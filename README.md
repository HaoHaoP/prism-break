# PRISM BREAK

A neon brick-breaker roguelike in a single HTML file. No build step, no dependencies, no assets — every brick, card and sound is generated by code.

**Play it: <https://prism.haohaop.com>**

![PRISM BREAK](assets/screenshot.png)

## The twist: light tones

Most brick-breakers only ask you to keep the ball alive. Here the ball carries one of three light tones — **cyan, violet, amber** — and every brick is tinted with one of the same three.

Hit a brick whose tone matches your light and it takes **double damage**, scores more, and charges your overdrive faster. So you are constantly deciding: chase the ball, or spend a beat switching tone to break the right column.

| Key | Action |
| --- | --- |
| `Q` / `E` | shift light tone (or click the swatches) |
| `1` `2` `3` | jump straight to a tone |
| `Shift` | spend a full **overdrive** meter |
| mouse / arrows | move paddle |
| click / `space` | launch ball |
| `P` | pause |
| `M` | mute |

## Overdrive

Every brick you break charges the meter at the bottom. When it fills, `Shift` fires a prism burst: every brick on the floor takes a hit, the screen flashes, and time drops to a third speed for a moment so you can reposition. Clear a dense floor in one press — or save it for the boss prism.

## Structure

- **10 floors**, each with a different generated layout, growing brick health, and the occasional indestructible strut that forces you out of a comfortable lane.
- **Every 5th floor** spawns a golden core prism with a deep health pool.
- **Clear floor 10** for the ending, then keep going into the endless mode.
- **Roguelike picks**: every cleared floor offers three of twelve upgrades — more balls, wider paddle, piercing shots, blast damage, auto-firing lasers, crits, floor shields, slow-motion cushion, extra lives.

Twelve upgrades, three max levels each, no duplicates while unpicked. Runs finish in five to fifteen minutes.

## Run it locally

```bash
git clone https://github.com/HaoHaoP/prism-break.git
cd prism-break
open index.html          # macOS
# or: python3 -m http.server 8080
```

That is the whole install. `index.html` is self-contained; you can also just download that one file.

## How it is built

- Plain JavaScript, `requestAnimationFrame`, no framework and no bundler.
- Canvas 2D with a fixed 960×640 logical resolution, letterboxed to the viewport, DPR-aware.
- Swept sub-stepping for collision so a fast ball never tunnels through a thin brick, plus anti-stall logic that re-aims a ball that has been grazing empty space.
- Sound is synthesised live with WebAudio oscillators — there are no `.mp3` files in this repo.
- Best score persists in `localStorage`.
